# Ghost Tap

Ghost Tap is an Android app that finds nearby devices, connects to them,
and puts their controls in plain English. Scan, connect, control.
No setup, no configuration.

## What it does

- Bluetooth scan with plain names, no hex, no jargon
- Tap a device and it connects and lays out the controls
- Network tools, NFC tools, Visual Intel (point the camera at a device),
  Investigations, and a built-in virtual ESP32 test board
- Termux runs underneath as plumbing, no setup screens

## Build

Open in Android Studio and build, or feed a ZIP of this repo to the
AndroidForge GitHub Actions workflow (drop a ZIP, run the workflow,
get an APK).

## Status

Solo project, in active development. Built and tested on a real phone.
